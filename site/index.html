Robustness

Two stricter checks

A random-day twin test for skill, and a blind second pass to check the extraction.

Random-day twin test

Each scored call gets a twin: same instrument, direction and threshold, scored on a random trading day from the previous ~6 months instead of the day it was made. 10,000 twin sets per channel. The twin p-value is the share of twin sets that did at least as well as the real calls; a Holm correction accounts for testing 22 channels at once.

Calls placed on random days hit about 46%, below 50% because a call has to clear a threshold to count.

The second pass also picked up more borderline, hedged remarks (152 calls), so which remarks count as calls is the least stable step, not the direction called. Sample hit rate was 47% under both passes.

Both passes used the same family of model, so this measures consistency, not full independence. Commands for both checks are in the GitHub repo: ytscore twins and ytscore agree.

How it works

From video to score in six steps.

01

Collect

Pull new videos

New uploads come from each channel's YouTube listing.

02

Transcribe

Turn captions into text

Captions are converted to clean text.

03

Extract

Record every call

An LLM reads each transcript and logs every call in a fixed schema: asset, direction for next session, weeks and months, targets, support and resistance, conditions, the timestamp and a short verbatim quote.

04

Join prices

Match to daily closes

Each call is matched to the instrument's daily closes: ES, NQ, gold, silver, oil, BTC, ETH, stocks and more.

05

Score

Measure what price did

From the last close before the video (or that day's close if it was recorded intraday or after the close) to the next close, and to the first close one week later.

06

Rank

Compare with chance

Each hit rate is compared with a coin flip and with simply always being long.

What counts as right

A call must clear a small move to count.

Threshold: 0.12% for index futures and gold; 0.24% for crypto, stocks, silver and miners.

Bullish

Right if price rises by more than the threshold.

Bearish

Right if price falls by more than the threshold.

Neutral

Right if price stays within the normal daily range.

Not scored

Calls with no clear short-term direction. The 1-week score uses a wider band.

Fair to creators

Every score traces back to the creator's own words.

Each score links to the video, the timestamp and the quote. All the code and the full scoring method are public on GitHub, so anyone can rerun it.

Think a call was misread? Open a GitHub issue with the video link and timestamp, and it gets corrected.

Limitations

  • One fixed month (Sep 24 to Oct 23, 2026), a single market regime; several Oct 13–23 videos were dated from clues in the video, usually a day before upload.
  • Small samples for many channels.
  • LLM extraction can misread sarcasm or hedged language.
  • Daily closes only, so no intraday stops or targets.
